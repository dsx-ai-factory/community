# DSX AI Factory Community

Community articles and discussions about the open-source components of the NVIDIA DSX
AI Factory.

This repository holds **articles and conversation, not product source code**. The
components themselves live in their own repositories in the
[`dsx-ai-factory`](https://github.com/dsx-ai-factory) organization.

## What you will find here

- **Articles** — release posts, technical deep dives, how-tos, success stories, event
  recaps, and contributor spotlights, published as a site from this repository.
- **[Discussions](https://github.com/dsx-ai-factory/community/discussions)** — questions,
  ideas, and open-ended conversation about the components and the articles.

## Contributing

Contributions are welcome from NVIDIA employees, partners, customers, and the wider
open-source community.

- Propose an article by opening an **Article proposal** issue. An editor will confirm the
  topic and a publishing slot before you write.
- Fix a typo, a broken link, or a stale version number by opening a pull request directly.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) first. All commits must be signed off
  (`git commit -s`) under the Developer Certificate of Origin.

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).

## Governance

[GOVERNANCE.md](GOVERNANCE.md) describes the roles, the content approval path,
the publishing schedule, and how outdated articles are marked.
