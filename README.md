# DSX AI Factory Community

DSX AI Factory Community publishes articles and hosts discussions about the
open-source components of NVIDIA's DSX AI Factory platform. It exists so a developer,
partner, or customer working with DSX has one place to find release notes, technical
deep dives, how-tos, and community conversation about the components as they ship.

This repository will publish release posts when a component ships or updates,
technical deep dives, how-tos, success stories, event recaps, and contributor
spotlights, as articles from this repository, indexed below.

**This repository does not contain source code.** Community articles and posts may
include example code snippets for illustration, but the projects named in the index
below each live in their own repository. To contribute to or download the source of a
named project, use the index below to find it.

## What You Will Find Here

Articles: release posts, technical deep dives, how-tos, success stories, event
recaps, and contributor spotlights, published as a site from this repository.

[Discussions](https://github.com/dsx-ai-factory/community/discussions): questions,
ideas, and open-ended conversation about the components and the articles.

## What Is DSX

DSX is NVIDIA's overarching brand for AI Factories: it spans hardware, data center
power and cooling infrastructure, and software, everything needed to plan, build, and
run a GPU-accelerated data center. It is organized into a handful of named brands,
each covering part of that scope:

![The DSX portfolio by brand: DSX Sim on top, DSX OS (highlighted, the largest concentration of open-source components) below it, then DSX Exchange (also highlighted), DSX Flex, and DSX MaxLPS.](content/posts/assets/dsx-stack.svg)

- **DSX OS** is the open-source IaaS/PaaS software that provisions, orchestrates, monitors, and serves inference across a cluster: cluster orchestration, infrastructure management, monitoring, resiliency, security, scheduling, workload management, and optimized inference.
- **DSX Exchange** is IT/OT infrastructure communication: the event bus and agent gateway that connect DSX clusters to building management and grid systems.
- **DSX Flex** and **DSX MaxLPS** cover power: grid integration, cooling efficiency, and dynamic power orchestration.
- **DSX Sim** models the other four, so an AI factory can be validated before it is built.

Some of DSX is open source, alongside domains such as hardware and facilities that are
not released as source code by their nature. DSX OS and DSX Exchange are where the
open-source components are concentrated: as of this page's last render, DSX OS
accounts for 44 open-source components and DSX Exchange
1, which is why they are highlighted above. DSX Flex and
DSX MaxLPS do not have open-source components in this index yet. The full list, each
shown against the DSX layer it occupies, is below.

Contributions are welcome from NVIDIA employees, partners, customers, and the wider
